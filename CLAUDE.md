## Project

CMS for a dog breed association covering all sighthound breeds (KChP project). Built with Next.js and Decap CMS.

## Stack

- **Framework:** Next.js
- **CMS:** Decap CMS
- **Package manager:** npm

## Commands

```bash
npm install       # install dependencies
npm run dev       # start local dev server
npm run build     # production build
npm run start     # run production build locally
```

## Notes

- Decap CMS config lives in `public/admin/config.yml`
- CMS collections define the content schema for breed pages and association content
